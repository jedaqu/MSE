## Scope

M1.11 turns the semantic guarantees established in M1.7–M1.10 into a reusable test harness for any implementation of `PersistenceBackend`.

The harness checks initial state, preparation invisibility, generation invariants, retained `PreparedState`, `Aborted` retry with the same `TransactionId`, committed idempotence, reconciliation, durability rejection for `Aborted` and `Unknown`, and explicit discard.

## Boundary

The harness depends only on `PersistenceBackend` and core semantic types. It does not know files, paths, record formats, checksums, `sync_all`, reopen mechanics, or physical recovery mechanisms.

Backend construction, reopening and physical recovery remain outside M1.11 because the current trait does not define a backend-neutral lifecycle for reconstructing an implementation from durable storage.
